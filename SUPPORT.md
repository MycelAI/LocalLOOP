# Getting help

localLOOP is an early-stage project and a **lab demo only**, maintained by one
person at Mycel UG (haftungsbeschränkt). There is no support service, SLA or
GitHub Discussions forum.

| You want to... | Go to |
| --- | --- |
| Report a bug, request a change or flag a docs problem | Open an issue on [MycelAI/LocalLOOP](https://github.com/MycelAI/LocalLOOP/issues/new/choose) using one of the [issue forms](.github/ISSUE_TEMPLATE/) |
| Ask a question or propose something privately | Email **dev@mycel-ai.de** |
| Propose a protocol change | Follow the RFC process in [CONTRIBUTING.md](CONTRIBUTING.md#protocol-changes-and-rfcs) |
| Report a security vulnerability | Email **dev@mycel-ai.de** privately, as described in [SECURITY.md](SECURITY.md). Never use a public issue. |
| Report a Code of Conduct concern | Email **dev@mycel-ai.de**, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-an-issue) |

Public documentation lives at https://loop.urbnia.com. The former
`github.com/local-loop-io/*` repositories are archived and read-only, so
issues can no longer be opened there; use
[MycelAI/LocalLOOP](https://github.com/MycelAI/LocalLOOP) instead.
